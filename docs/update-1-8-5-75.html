What's New

Save any open page as a single encrypted HTML file. Only your master password can open it again.

1

Click the new button

Open the extension and press the page-with-a-lock icon in the action bar. The current tab is saved right away, with no extra password prompt.

2

Get an encrypted file

The page, with its styles and images, is packed into one .html file and encrypted with AES-256-GCM. The file name never reveals the page title or address.

holy-private-page-20261010-120000.html
3

Open it anywhere

Open the file in a modern browser, enter your master password and the page is decrypted on the spot, offline and without the extension.

Open

Good to know

  • Your master password is never stored in the file. The key is derived from it with PBKDF2 (600,000 iterations).
  • Scripts, hidden form fields and typed passwords are removed from the saved copy.
  • The opened page runs in a sandboxed frame with no scripts and no network access.
  • If you change your master password later, older files still open with the old one.
  • There is no recovery: if the master password is lost, saved pages cannot be opened.
  • Some pages may look different from the original. Images that other sites block and dynamic content may not be captured, and browser pages such as chrome:// cannot be saved.
